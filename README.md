# ascend
Autonomous System for Climbing, Exploration, Navigation, and Dynamics

ASCEND (Autonomous System for Climbing, Exploration, Navigation, and Dynamics) is an open-source quadruped robotics platform focused on developing a capable, modular, and well-documented legged robot from the ground up.

The project combines mechanical engineering, electronics, embedded systems, software, and manufacturing into a single open platform. Every stage of development—from concept sketches and CAD models to custom PCBs, firmware, testing, and manufacturing—is documented to provide a valuable learning resource for the robotics community.

ASCEND is designed around three core principles:

Engineering First – Every design decision is driven by analysis, testing, and continuous improvement rather than simply replicating existing robots.
Open Development – CAD, electronics, software, documentation, and manufacturing resources are developed openly to encourage collaboration and learning.
Continuous Innovation – The platform is intended to evolve over time, exploring new mechanical designs, custom electronics, advanced locomotion, perception, and future actuator technologies.
Project Goals
Design a high-performance quadruped robot from scratch.
Develop a modular mechanical architecture that is easy to maintain and expand.
Learn and document professional CAD design using Onshape.
Design custom PCBs and electronics tailored to the robot.
Develop reliable embedded firmware and robot control software.
Implement inverse kinematics, gait generation, and dynamic locomotion.
Optimize parts for CNC machining, additive manufacturing, and efficient assembly.
Document the complete engineering process to create a valuable educational resource.
Build an open-source platform that encourages collaboration and contributions.
Continuously improve the platform through testing, iteration, and research.

ASCEND is more than a robot—it is a long-term engineering project dedicated to learning, innovation, and sharing knowledge with the open-source robotics community.
